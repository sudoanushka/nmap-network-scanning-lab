# nmap-network-scanning-lab
Hands-on Nmap network scanning lab documenting host discovery, port scanning, service detection, OS detection and security analysis.

About This Project

This repository documents my hands-on practice with Nmap in a controlled cybersecurity lab environment. 

The objective of this project is to understand network reconnaissance, identity open ports and services, and learn how to interpret Nmap scan results from a defensive cybersecurity perspective.

Objectives
1. Learn fundamentals of Nmap
2. Perform host discovery
3. Identify open ports
4. Identify running services
5. Practice service and version detection
6. Practice OS detection
7. Analyze and document scan results

Lab Environment
1. kali Linux
2. Nmap

Nmap Techniques Practiced
1. Host Discovery
2. Basic Port Scanning
3. Service  Detection
4. OS Detection
5. Comprehensive Scanning

Scan observations will be documented here as the project develops.
